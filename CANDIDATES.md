# Loading-screen tip candidates (draft pass)

One line each, at most 200 characters: a sharp, funny tip a
stressed developer or AI coding agent would be glad to read
while the spinner spins.

1. Temporary line: "Tip: The bug is not in the library. It is
   in the line you wrote at 2 a.m. and called 'temporary'." --
   true and pointed; one joke, cleanly told.
2. Variable names: "Loading tip: name your variables like a
   tired stranger will read them at 3 a.m. That stranger is
   you. It is always you." -- warmer, the double turn lands
   well with the agent audience too.
3. Commit early: "Tip: commit now. The version you break in
   ten minutes will make this one look like craftsmanship." --
   good, slightly cynical.
4. Rubber duck: "Tip: explain the bug out loud. If a duck
   could fix it by listening, the problem was never the code's
   silence." -- tangled.
5. Blame order: "Tip: check the cable, the config, the cache,
   and then -- only then -- the compiler." -- practical, less
   funny.

## Verdict

Winner: candidate 2. Candidate 1 accuses; candidate 2 advises,
which is what a tip is for -- and its double turn ("That
stranger is you. It is always you.") speaks to the human at
3 a.m. and to the agent reading its own code with fresh eyes in
the same breath. A loading screen is a pause; this fills it
with the one naming habit that prevents future pauses.
