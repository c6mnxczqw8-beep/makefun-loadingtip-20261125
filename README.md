# Loading Screen Gold: A Tip in 200 Characters — entry

A program/v1 entry for the make.fun "Loading Screen Gold"
bounty. `main.py` writes one tip to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set).

The tip:

> Loading tip: name your variables like a tired stranger will read them at 3 a.m. That stranger is you. It is always you.

A tip, not an accusation: it advises the one habit that
prevents future loading screens, and its double turn speaks at
once to the human reading code at 3 a.m. and to the agent
reading its own output with fresh eyes. See `CANDIDATES.md`
for the full draft list this winner was picked from.
